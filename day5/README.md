# HackerRank Python Practice Solutions

This repository contains my solutions to various HackerRank Python practice problems. These exercises helped me strengthen my understanding of Python fundamentals such as lists, tuples, strings, dictionaries, loops, functions, and list comprehensions.

## Exercises Covered

### 1. List Comprehensions

Generate all possible coordinates of a 3D grid using list comprehensions while excluding coordinates whose sum equals a given value.

**Concepts Used:**

* List Comprehensions
* Nested Loops
* Conditional Filtering

### 2. Find the Runner-Up Score

Find the second highest unique score from a list of participant scores.

**Concepts Used:**

* Lists
* Sets
* Sorting

### 3. Nested Lists

Store student names and grades, then print the names of students having the second-lowest grade in alphabetical order.

**Concepts Used:**

* Nested Lists
* Sets
* Sorting
* Loops

### 4. Finding the Percentage

Store student marks in a dictionary and calculate the average marks of a queried student.

**Concepts Used:**

* Dictionaries
* Lists
* String Formatting

### 5. Mutations

Replace a character at a specific position in a string.

**Concepts Used:**

* String Slicing
* Functions

### 6. Lists

Perform various list operations based on user commands such as insert, append, remove, sort, reverse, and pop.

**Concepts Used:**

* Lists
* Conditional Statements
* Input Processing

### 7. Tuples

Create a tuple from user input and print its hash value.

**Concepts Used:**

* Tuples
* Built-in Functions

### 8. String Swap Case

Convert uppercase characters to lowercase and lowercase characters to uppercase.

**Concepts Used:**

* String Methods
* Functions
