# Python String Formatting Exercises

This repository contains solutions to two Python programming exercises involving string manipulation and formatting.

## Exercise 1: Alphabet Rangoli

### Problem Statement

Print an alphabet rangoli of a given size. A rangoli is a symmetric pattern made using lowercase English alphabets.

### Function

```python
print_rangoli(size)
```

### Features

* Generates a symmetric alphabet pattern.
* Uses lowercase English letters (`a-z`).
* Dynamically adjusts pattern width based on the input size.

### Example

For `size = 3`:

```text
----c----
--c-b-c--
c-b-a-b-c
--c-b-c--
----c----
```
